## 📖 项目简介 (Overview)

建筑施工现场结构与通道处于高频动态更迭中，脚手架搭设、模板支架阻隔、材料临时堆放以及未封闭井道的“烟囱效应”，导致传统静态逃生路线在火灾发生时全面失效。

**FireGuard（筑安·火眼）** 摒弃了纯大模型直接计算生命路线的高危方案，开创性构建了 **“神经-符号”混合双轮驱动架构（Hybrid Neuro-Symbolic Architecture）**，并依托 **Three.js 构建 3D 立体施工作业层数字孪生** 与 **Qwen3 全套专业模型矩阵**：
- **感知端 (`qwen3-vl-flash`)**：利用百炼毫秒级视觉模型实时解析监控抓拍画面，秒级研判明火羽流、黑烟扩散与脚手架坍塌占道；
- **协同端 (`qwen3.7-plus`)**：安全总监 Copilot 对话中枢，结合 GB/T 50720 规则引擎进行深层次现场态势问答与合规审计；
- **播报端 (`qwen-turbo`)**：为各班组工友秒级生成地道的**方言定向语音避险指令（支持湖南话、四川话、普通话）**；
- **规范端 (GB/T 50720-2011)**：内嵌工程消防标准强约束（通道净宽、疏散极限距离、烟囱效应阻断）；
- **求解端 (动态加权 A\*)**：确定性图搜索算法，在 4.2ms 内输出 100% 安全避障且双出口负载均衡的疏散路径；
- **渲染端 (Three.js 3D)**：完整立体展现核心筒、周圈刚性脚手架、发光逃生光管、真实粒子烈火与黑烟扩散。

## ⚡ 快速启动 (Quick Start)

本项目设计遵循极简工程化规范，**内置多线程异步服务器，无任何强制性重型外部依赖**，克隆后即可秒级运行。

### 1. 克隆代码仓库
```bash
git clone git@github.com:YangguangZhou/FireGuard.git
cd FireGuard
```

### 2. 配置可选环境变量 (选填)
如需连接阿里云百炼官方 Qwen-VL 接口，可配置 API 密钥（若不配置，系统将自动启用内置的高保真实机推演仿真缓存）：
```bash
export DASHSCOPE_API_KEY="your-api-key"
```

### 3. 启动态势指挥大屏
```bash
python3 server.py
```
终端输出如下提示即表示启动成功：
```text
=================================================================
🚀 FireGuard（筑安·火眼）智慧工地态势指挥大屏服务已启动!
👉 本地访问地址: http://127.0.0.1:8000
👉 局域网访问地址: http://0.0.0.0:8000
=================================================================
```
在浏览器中打开 `http://127.0.0.1:8000`，即可进入充满未来科技感的智能指挥驾驶舱。

### 4. 运行自动化测试验证
```bash
python3 -m unittest tests/test_agent_workflow.py
```

## 🎭 现场答辩“三幕剧”实机推演指南 (Demo Walkthrough)

在指挥大屏上方点击演练按钮，可向评委完整展示智能体的自主决策演进：

1. **第一幕：常态安全巡检合规（绿色）**
   - 展示 4 位在建高层工友正常施工作业；
   - 智能体后台静默巡检，所有通道净宽均满足 GB/T 50720 规范，出口 A、B 畅通无阻。
2. **第二幕：突发火情动态疏散响应（红色警报）**
   - 模拟配电箱过载引燃木模板与外架防护网；
   - Qwen-VL 视觉感知识别到东干道烈火与浓烟，智能体硬隔离东侧主楼梯（出口 A）；
   - 确定性 A* 算法瞬间重新规划，工友引导线即刻转向西侧外挂避难爬梯（出口 B），安全帽语音指令同步推送。
3. **第三幕：通道阻断二次重规划（橘黄高潮）**
   - 模拟西侧走廊突发脚手架支架倾倒，实测净宽骤降至 $0.35\,\text{m}$（违背规范）；
   - 智能体检测到次生阻断，5秒内完成全局二次重规划，将受困木工组调流至南立面悬挑避难平台 C（启动登高云梯车外部接驳方案）；
   - 点击右上角 **“导出处置记录单”**，一键调阅合规应急清单。
