## 一、架构设计理念：神经-符号混合智能体 (Neural-Symbolic Agent)

在施工现场生命安全关键场景中，纯大语言模型存在两个致命短板：
1. **黑盒幻觉不可控**：绝不能让大模型自由生成逃生路线，极易产生穿墙、走火路、进死胡同等致命错误；
2. **缺乏空间拓扑度量感知**：大模型无法直接完成带物理约束（净宽、拥挤度、坡度）的毫秒级图最优路径搜索。

FireGuard 采用国际前沿的**“神经-符号”（Neural-Symbolic）分层解耦架构**：
- **神经网络（多模态大模型 Qwen-VL）**：负责非结构化现实环境的理解（看懂监控、识别火焰浓烟、识别脚手架坍塌）；
- **符号中枢（GB/T 50720 规则引擎 + 施工拓扑网格）**：将视觉常识转换为严密的工程规范硬约束与带权图模型；
- **确定性算力核心（加权 A\* 算法）**：负责严格数学收敛的生命安全路径寻优。

## 二、四大功能分层与数据流解析

### 1. 多源多模态感知输入层 (Perception Layer)
- **视觉数据流**：施工现场 RTSP 1080P 高清摄像头推流至 Qwen-VL 多模态模型，提取空间方位、置信度、火焰强度与烟气羽流扩散方向。
- **时序物理传感器**：光电烟感（PPM）、结构温度（℃）、一氧化碳（CO）通过 MQTT 网关毫秒级上报，多源融合交叉消除误报。
- **人员动态追踪**：通过工友佩戴的 UWB 智能工牌及智能安全帽，实时映射至作业层拓扑网格节点。

### 2. FireGuard 认知决策中枢层 (Cognitive Agent Core)
- **ReAct 自主决策状态机**：
  - `Thought`: 综合研判火情与各通道安全裕度；
  - `Action`: 调用 GB/T 50720 规则引擎执行合规过滤；
  - `Observation`: 监控双出口负载均衡与疏散距离；
  - `Re-planning`: 遇到次生阻断即刻触发二次重规划。
- **GB/T 50720 规范规则引擎**：强制校验地面临时通道 $\ge 1.5\,\text{m}$、利用既有结构 $\ge 1.0\,\text{m}$、外架爬梯 $\ge 0.6\,\text{m}$，违规通道成本直接置为 $\infty$。
- **烟气动力学物理推演**：根据水平扩散速度（$0.5 \sim 0.8\,\text{m/s}$）与竖向管道井“烟囱效应”（$3.0 \sim 5.0\,\text{m/s}$）推演动态危险时空窗口。

### 3. 确定性计算与规划引擎 (Deterministic Engine)
- **动态综合成本评估方程**：
  $$\text{Cost}_{ij} = L_{ij} \times \left(1 + \alpha \cdot R_{\text{fire}} + \beta \cdot R_{\text{smoke}} + \gamma \cdot \text{Crowd}\right) + \text{Penalty}_{\text{obstacle}}$$
- **加权 A\* 多目标求解**：欧氏距离启发函数保证毫秒级（$\le 5\,\text{ms}$）收敛，严格绕开火源硬隔离区。
- **双出口均衡分流机制**：严格遵循 GB 50016 规范，在东侧主楼梯（A）与西侧外架爬梯（B）之间实施动态分流，规避踩踏。

### 4. 多端人机协同输出交互层 (Interaction Layer)
- **智慧工地指挥大屏**：基于 Vue 3 + Tailwind CSS 构建现代化深色科技看板，动态展示 2D 拓扑光流与智能体推演日志。
- **工友智能安全帽终端**：下发个性化语音指令（如“李师傅：东主楼梯已阻断，请立即向西走避难爬梯！”）并配合声光定向导引灯。
- **规范应急处置记录单**：自动导出包含被困人员坐标清单、火源方位的标准处置表，供入场消防特勤队无缝接驳指挥。
