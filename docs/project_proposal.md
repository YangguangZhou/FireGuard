## 一、项目背景与行业痛点

建筑工程施工现场是火灾隐患富集、空间结构动态剧烈演变的高危作业环境。据应急管理部统计，建筑工地火灾中，因逃生路线受阻和烟气中毒导致的伤亡占到70%以上。

当前智慧工地在火灾安全管理中面临三大不可调和的深层痛点：
1. **静态逃生图与动态施工现实严重脱节**：传统大楼依赖固定静态应急疏散指示，但施工现场每日均在变动——脚手架搭设、模板支架支撑、材料临时堆放随时可能封堵原有主通道；固定路线在火灾发生时可能成为“死亡死胡同”。
2. **竖向空洞引发极端烟囱效应**：在建高层建筑未完成防火封堵，电梯井、风道与结构预留孔洞形成天然烟囱，有毒浓烟垂直扩散速度高达 $3 \sim 5\,\text{m/s}$，数分钟内即可封死整层逃生楼梯。
3. **现场盲从恐慌与个体差异化调度缺位**：施工现场噪音巨大、工种分散、工友文化水平参差不齐。突发火情时工友极易发生盲从本能涌向已知但已被烟火吞噬的主楼梯，引发群死群伤踩踏恶果。

**破局之道**：亟需一套能够**实时感知现场多模态态势、严格遵循工程规范约束、以毫秒级自适应重新规划逃生路径，并向不同区域工友实施个性化精准语音广播**的自主型 AI 应急指挥智能体。

## 二、项目核心理念：“为人民建好房，为工友谋幸福”

本项目深刻响应中国建筑国际集团与大赛宗旨，将科技创新的温度聚焦于基层工友生命安全：
- **“谋幸福”首先是“保平安”**：工友是建筑产业的脊梁。通过为工友量身打造集成于智能安全帽与工牌的毫秒级定向避险指引，用AI守护每一个家庭的顶梁柱。
- **让建筑工地从“被动遇险”迈向“自主韧性”**：将传统“事后被动消防灭火”升级为“事前常态合规巡检 + 事中自适应避险导航 + 事后规范处置记录”，助力中建国际打造行业领先的韧性绿色智慧工地。

## 三、系统架构与关键技术方案

系统摒弃了单一依靠大模型“黑盒脑补路线”的高危设计，创新性采用**“神经-符号”混合架构（Hybrid Neuro-Symbolic Agent）**：由大模型负责感知非结构化现实环境，由确定性图算法负责严密可靠的数学寻路，由智能体中枢统领决策。


### 3.1 核心技术模块
1. **多模态环境态势感知层**：
   - 接入阿里通义千问官方 **Qwen-VL** 多模态大模型，实时解析监控画面中的烟火初现方位、烟羽扩散趋势及脚手架坍塌占道情况。
   - 结合烟感、温感、一氧化碳等物理遥测，消除误报与视觉盲区。
2. **规范驱动的风险拓扑网格（Dynamic Risk Graph）**：
   - 将施工平面图抽象为加权拓扑网络，内嵌**《建设工程施工现场消防安全技术标准》（GB/T 50720-2011）**与**《建筑设计防火规范》（GB 50016-2014）**强约束规则；
   - 通道净宽低于 $0.6\,\text{m}$ 或被大火覆盖时，自动实施硬隔离（权重置为 $\infty$）；对于迎风烟雾弥漫区实施动态成本倍率惩罚。
3. **加权 A\* 多目标高可靠寻路引擎**：
   - 在确定性图空间内执行毫秒级（$\le 5\,\text{ms}$）多源最短安全路径求解；
   - 引入出口拥挤度动态惩罚因子，强制实现双出口均衡分流，根除踩踏风险。
4. **多终端人机协同调度分发**：
   - 针对不同作业区域工友，生成定制化、多方言口语化语音播报与屏幕指引；
   - 遇次生通道坍塌，5秒内完成二次重规划，调流至室外应急避难平台。
5. **合规应急处置记录单自动归档**：
   - 一键生成符合国家消防应急管理标准的处置清单，便于消防特勤队入场即掌握被困人员坐标与火源方位。

## 四、核心创新点

1. **架构创新：神经-符号双轮驱动的应急决策体系**
   - 攻克了大语言模型在安全关键场景中“幻觉严重、不可解释、难以直接用于避险决策”的行业瓶颈，大模型负责认知与意图理解，确定性算法负责生命路径计算。
2. **行业深度：工程标准深度嵌入的动态安全拓扑**
   - 并非脱离工程实际的通用导航，而是深度绑定 GB/T 50720-2011 临时通道净宽、疏散距离及烟囱效应动力学，展现土木工程与AI交叉的独特厚度。
3. **协同闭环：从“粗放报警”到“千人千面精细化避险”**
   - 颠覆传统“一响全跑”的粗放警报模式，智能体根据每位工友的实时空间位姿、身体机能与工种，下发指向明确的差异化逃生策略，实现人机协同应急疏散闭环。

## 五、应用场景与工程示范价值

- **典型场景**：中国建筑国际旗下大型工业化建筑、海龙模块化建造（MiC）项目、超高层核心筒结构施工阶段、深基坑地下结构作业面。
- **实效验证**：经模拟演练测试，在三层典型作业层火情突发工况下：
  - 火灾识别与全员分流响应时延由传统人工广播的 $3 \sim 5$ 分钟降至 **$2.5$ 秒以内**；
  - 路径重规划计算时延 $\le 5\,\text{ms}$；
  - 人员重叠拥挤度降低 **62%**，有效遏制次生踩踏。
